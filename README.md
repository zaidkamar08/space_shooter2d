# Space Shooter 2D

A 2D space shooter game built with Godot Engine. Work in progress.

## About

A top-down space shooter where you fight waves of enemies. Built from scratch using Godot 4 and GDScript.

## Current status

- Player movement and shooting
- Enemy spawning system
- Bullet mechanics
- Game manager

## Still building

- Score system
- Multiple enemy types
- Sound effects
- Main menu and game over screen

## Tech used

- Godot 4
- GDScript

## How to run

1. Download and install Godot 4 from godotengine.org
2. Clone this repo
3. Open Godot, click "Import" and select the project.godot file
4. Press F5 to run the game

## What I learned

- Scene and node system in Godot
- GDScript basics
- 2D physics and collision detection
- Enemy spawning patterns
